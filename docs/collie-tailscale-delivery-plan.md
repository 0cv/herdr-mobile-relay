## Product choices and limits

- **Two separate, honest Tailscale contracts.** (1) Managed foreground Serve: the relay process owns a held LocalAPI watcher/session and exact conditional route, private control, O and bound backend; no route adoption, CLI Serve child or global reset. (2) Explicit **external/BYO HTTPS Serve** for an operator with an existing tailnet route: Herdr never configures, adopts, claims or tears down that route, and stopping only stops its relay. Do not give BYO managed-mode anti-port-reuse or watcher guarantees. Preserve Cloudflare/gateway modes. This extracts Collie's useful existing-tailnet onboarding without importing a matching-backend-as-ownership shortcut.
- **Borrow Collie's operational clarity**: actionable status that separates installed client/daemon, local listener, public HTTPS reachability, bundle identity, invitation/credential state, ownership and cleanup/quarantine, and whether ingress is externally operated. Keep information private/redacted; no session IDs, tokens, proof files or setup fragments in logs/status. Stable HTTPS origin/device reuse and restart/reconnect should be simple; foreground managed mode does **not** turn into an unattended background service merely to match Collie.
- **Do not copy** optional/empty-registry pairing, authorization only on writes, unencrypted app JSON, blind auto-restart, arbitrary Tailscale versions, generic GUI discovery via unbounded `lsof`, or crew/polling rewrites. Preserve Herdr's mandatory production E2EE and device roles. No performance superiority claim without measurements.
- **Supported-cell honesty:** current exact-pin Linux/open-source Darwin Unix-daemon adapter is source-supported but not real-daemon qualified. Add a *separate exact MacSys v1.102.4 experimental adapter* only if source/public signed package evidence supports the complete CLI-facing profile and safe admin-group LocalAPI token transport; otherwise explicitly refuse. App Store, other GUI/build variants and generic CLI-to-daemon OSVariant inference remain unsupported/unqualified. Static package evidence under `/var/folders/j6/j1mh02615qd312vt7yhx47600000gp/T/tailscale-macos-static.9MGhQq/`; source pin `bbcd7d1fc2054b9189ebc1531acf74bd880ca0c8`, candidate long `1.102.4-t3caf7d9e7-g084ee3b64`, supplemental `084ee3b64537a1276e56fc38cdf0a711da9f4936`. No real Mac/token probe.
- **Safety boundary:** cooperating writers only; arbitrary same-UID/root can ignore locks or replace same-session-key config. Watcher close has no remote GC acknowledgement and involuntary exit may erase changed same-key state. Never promise unconditional same-key preservation, raw StateStore erasure, drained ingress, or survival after process/kernel loss. R1 F009/F012 remain historically open; fulfill their operational obligations in new code/tests rather than editing that ledger.
